Embedded Systems: From Electrons to Firmware

A free, self-paced course in embedded development, from Ohm's law and logic gates to drivers, an RTOS and a finished project of your own. Every exercise runs in the Wokwi simulator inside VS Code, so you don't need any hardware.

Version 0.0.3 · Changelog and known issues · Source code and projects on GitHub

What this is

Embedded systems are the small computers inside everyday things: a thermostat, a 3D printer, a car's window motor. This course teaches how they work and how to program them, one short lesson at a time. It starts with electricity and digital logic, moves on to how a microcontroller runs C code, and then covers peripherals, interrupts, testing, real-time operating systems (FreeRTOS and Zephyr) and communication buses.

It has 120 lessons in 11 parts, 6 labs that combine several lessons, and a checkpoint exam at the end of most parts. It ends with a capstone: a temperature controller for a filament dryer, built step by step, with tests and continuous integration. The boards are a Raspberry Pi Pico and an STM32 "Blue Pill", both simulated.

How to use it

  1. Read. Start with the first lesson below and go in order. Each lesson is short and ends with a quiz. You can read on any device, phone included.
  2. Do the exercises. Clone the repository and run python tools/serve.py in it: it opens the course at http://localhost:8000. Lesson 1 installs the tools.
  3. Track your progress. Mark each lesson complete when you're done. Progress is saved in this browser only, so use Export progress below now and then as a backup.
  4. Ask. The AI agent in the workspace is your teacher: ask it anything that's unclear.
  5. Optional: if you have real hardware, the hands-on bench labs at the end of this page take the exercises onto a real board.
