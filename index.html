Embedded Systems: From Electrons to Firmware Engineer

An introductory course in embedded development, from Ohm's law to a Zephyr-based portfolio project. Every exercise runs in the Wokwi simulator inside VS Code.

Version 0.0.2 · see CHANGELOG.md for known issues

Work through the lessons in order. Each one is short and ends with a quiz; mark it complete when you're done and your progress is saved in this browser. You can read the course on any device, phone included, at its website. To do the exercises, clone the repository and open it with python tools/serve.py (it opens http://localhost:8000). Progress is saved in each browser separately, so use Export progress below now and then as a backup. Keep the reference sheets open while you work. Hands-on projects live in the projects/ folder, one folder per lesson.

Your teacher is the AI agent in this workspace. Ask it anything that's unclear, ask for an extra exercise, or ask it to quiz you on older lessons.
