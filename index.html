What and Why?

This course stared as a series of helping lessons for my friend who wanted to learn some embedded development. I did not know what resources to recommend even though multiple courses can be found online. I guess now we can add one more to the list. However I hope this one to be a bit different. After setting some lessons up for the days topic which was UART communication, I thought that maybe I could set more structured lessons up for him but also for myself as a resource that I could easily go back to refresh my memory on any topics and in some learn something new. I thought what topics had been most influential in my own rather short learning period in university and after going back and forth with Claude I decided to settle roghly on the structure you find now. And yes, if you're wondering this whole course is 90% vibecoded. Most of the resources and materials have been checked and verified. (Hopefully some day all! And if you have any suggestions, PR's are welcome!) Enjoy and I hope you learn something new since thats why we're all here anyways!

Course structure

Course is split in 11 parts. Part 0 is where you set this course up locally on your machine. Real learning starts in Part 1. Last few parts are rather optional and the meat and potatoes definitely are in the parts 1-8. I recommend you to go in order although you can jump around if you feel comfortable with the topics. Also, try the search to look stuff up. It's really nice! ;)

At the end there are some optional hands on exercises which are also mentioned at the end of each part. You can do them while progressing through the course but they are not mandatory. They will give you some hands on real world experience with the topics which the simulators never can. If you do not have any hardware it's possible to also just do the simulator exercises since they cover most of the stuff anyways!

How to use it
  1. Read. Start with the first lesson below and go in order. Each lesson is short and ends with a quiz. Lessons tagged optional (PIO, the Zephyr part, and four overview lessons in Part 9) go deeper or sideways. Nothing on the core path needs them, and they don't count towards your progress. You can read on any device, phone included.
  2. Do the exercises. Clone the repository to get the projects. Lesson 1 installs the tools.
  3. Track your progress. Mark each lesson complete when you're done. Progress is saved in this browser only, so use Export progress below now and then as a backup.
  4. Ask. The AI agent in the workspace is your teacher: ask it anything that's unclear.
  5. Optional: if you have real hardware, the hands-on bench labs at the end of this page take the exercises onto a real board.

What's where
FolderWhat's in it
lessons/The lesson pages. This page links to all of them, in order.
projects/One folder per hands-on exercise, named after its lesson. Each has a starter/ to work in and a solution/ to compare with.
reference/Reference sheets: glossary, formulas, register and API cheat sheets. Keep them open while you work.
templates/Empty projects for each board, to start your own.
tools/Scripts: setup.py installs the tools, build.py builds a project. tools/maintainer/ holds the scripts that build this website; you won't need them.
third_party/Libraries the projects use: CMSIS, the STM32 HAL, FreeRTOS and the test frameworks.
Your teacher is the AI agent in this workspace. Ask it anything that's unclear, ask for an extra exercise, or ask it to quiz you on older lessons.
