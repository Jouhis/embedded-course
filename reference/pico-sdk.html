SIO register offsets (base 0xD0000000)

OffsetNameOperation
0x004GPIO_INRead the pad levels.
0x010GPIO_OUTRead or write the output levels.
0x014GPIO_OUT_SETWrite: GPIO_OUT |= w.
0x018GPIO_OUT_CLRWrite: GPIO_OUT &= ~w.
0x01CGPIO_OUT_XORWrite: GPIO_OUT ^= w.
0x020GPIO_OEOutput enable, 1 is output.
0x024, 0x028, 0x02CGPIO_OE_SET, GPIO_OE_CLR, GPIO_OE_XORAtomic set, clear and toggle of the output enables.

Source: RP2040 datasheet §2.3.1.7, Tables 16 to 24. The set, clear and XOR aliases are write-only, so a read returns the register, not the alias.

Baud divisor: total64 = (4 × clk_peri + baud/2) / baud, then IBRD = total64 / 64 and FBRD = total64 % 64. At 125 MHz and 115200 baud: IBRD 67, FBRD 52 [§4.2.3.2.1, §4.2.7.1]. A byte is 10 bits on the wire, about 87 µs at 115200.

PIO instruction words (RP2040 datasheet section 3.4)

Bits 15:13InstructionNotes
000JMPCondition in bits 7:5, address in bits 4:0
001WAITPolarity, source, index
010INSource, bit count
011OUTDestination, bit count (32 is written as 00000)
100PUSH or PULLBit 7 selects PULL (1) or PUSH (0). Bit 5 is block.
101MOVDestination, operation, source
110IRQClear, wait, index
111SETDestination, 5-bit data

Bits 12:8 are the delay (and side-set, when configured) for every instruction. OUT destinations: 000 PINS, 001 X, 010 Y, 011 NULL, 100 PINDIRS, 101 PC, 110 ISR, 111 EXEC.
