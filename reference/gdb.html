GDB commands

Lessons 32 and 54. The commands for stepping, breakpoints, watchpoints and memory, with the Wokwi setup. In VS Code's debug console, prefix a GDB command with -exec.

Starting the session

StepNote
Build with Ctrl+Shift+BThe build keeps -g and uses -O3, so stepping may skip lines.
F1 → Wokwi: Start SimulatorStart the simulator before the debugger.
F1 → Wokwi: Start Simulator and Wait for DebuggerPauses before the first instruction until GDB attaches.
F5Connects to localhost:3333, the gdbServerPort in wokwi.toml.

Running and stepping

CommandShortDoes
continuecRun until the next stop.
nextnRun one source line, stepping over calls.
stepsRun one source line, stepping into calls.
finishRun until the current function returns.
stepi, nextisi, niRun one machine instruction.
until LINEuRun until a line is reached in the current frame.

Breakpoints and watchpoints

CommandDoes
break main, break file.c:42Stop at a function or a line. Hardware breakpoints: 4 on the M0+ [§2.4.2.4].
tbreak LOCATIONA breakpoint that deletes itself after the first stop.
watch EXPRStop when the value of EXPR changes. Hardware watchpoints: 2 on the M0+ [§2.4.2.4]. Confirm the simulator stops before you rely on it.
rwatch EXPR, awatch EXPRStop on a read, or on any access.
info breakpointsList breakpoints and watchpoints with their numbers.
delete N, disable NRemove or disable breakpoint or watchpoint N.

Inspecting state

CommandDoes
print EXPR, print/x EXPRShow a value, optionally in hex.
x/NFU ADDRExamine memory. N count, F format (x hex, d decimal, s string), U unit (b byte, h halfword, w word). Example: x/8xb &frame.
info registersr0 to r12, sp, lr, pc and xPSR. Lesson 31.
bt, backtraceThe call stack, from the current function to main.
frame N, up, downMove to another frame in the call stack.
display EXPRShow EXPR at every stop.
set var NAME = VALUEChange a variable while stopped.
info symbol ADDR, info address NAMEFind what is at an address, or where a symbol lives.

Reading a watchpoint stop

A watchpoint stop prints Old value, New value and the location. The location is the instruction that made the store, which is often a different variable's name. Run bt to see the caller, and x around the address to see the neighbours.
