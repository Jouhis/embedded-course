ARM Thumb-2 quick reference

Lessons 29 and 32. The 16-bit encodings you meet in a disassembly. Each row was checked by assembling the instruction with the Arm GNU toolchain and reading the bytes back with objdump. The formal encodings are in the Armv7-M ARM (DDI0403), which we did not read for this sheet.

Reading a field

  1. Write the value in binary, 16 digits.
  2. Match the fixed bits to find the instruction.
  3. Read the fields from the bit positions in the table.
  4. Registers are 3 bits in these forms, so they name R0 to R7.

Condition codes for Bcond

condNameMeaning
0000EQEqual (Z set). Seen in beq.n, 0xD006.
0010CS / HSCarry set; unsigned greater than or equal. Seen in bcs.n, 0xD2FB.

Only these two codes are checked against the toolchain here. The other codes are listed in the Armv7-M ARM (DDI0403).
