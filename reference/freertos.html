FreeRTOS API

The calls used in Part 7 and Lab 5, on the Cortex-M3 port of FreeRTOS V11.2.0 in third_party/FreeRTOS-Kernel. Each row names the lesson where it is taught. Source: the API reference on freertos.org and the kernel source.

Tasks and time

CallUseLesson
xTaskCreate(fn, name, stack_words, arg, prio, &handle)Create a task; stack depth is in words87
vTaskStartScheduler()Start the kernel; does not return on success87
vTaskDelay(ticks)Block for ticks from now (drifts with work time)87
vTaskDelayUntil(&last, ticks)Block until last + ticks; updates last (fixed period)87
xTaskGetTickCount()Tick count from a task (1 tick = 1 ms at 1 kHz)87, 90
xTaskGetTickCountFromISR()Tick count from an interrupt89, Lab 5
vTaskDelete(NULL)Delete the calling task (needs INCLUDE_vTaskDelete)90, Lab 5
uxTaskGetStackHighWaterMark(h)Fewest free words ever (needs INCLUDE_uxTaskGetStackHighWaterMark)91, Lab 5
pdMS_TO_TICKS(ms)Convert milliseconds to ticks87
