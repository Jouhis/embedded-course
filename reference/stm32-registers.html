A write to a peripheral whose clock is off is ignored, with no fault. The clock is the first thing to check when a register write seems to do nothing.

GPIO port: CRL (pins 0 to 7) and CRH (pins 8 to 15)

Each pin has a 4-bit field. Pin n sits in CRL when n is below 8, and in CRH otherwise. Its field starts at bit (n mod 8) × 4. So PC13 is at bit 20 of CRH, and PA10 is at bit 8 of CRH.

Field bitsNameValues
3:2CNF (configuration)For outputs: 00 push-pull, 01 open-drain, 10 alternate push-pull, 11 alternate open-drain. For inputs: 00 analog, 01 floating, 10 pull-up or pull-down (the choice is in ODR), 11 reserved.
1:0MODE00 input, 01 output at 10 MHz, 10 output at 2 MHz, 11 output at 50 MHz.
Use4-bit fieldLesson
Output, push-pull, 2 MHz0x267, 69
Alternate push-pull, 50 MHz (USART TX)0xB66, 70
Input, floating (USART RX)0x470
Input, pull-up or pull-down0x8 (then set ODR bit to pick)69, 70

Mask-and-set pattern: GPIOC->CRH = (GPIOC->CRH & ~(0xFU << 20)) | (0x2U << 20);

GPIO data registers

RegisterOffsetUse
IDR0x08Read the pin level (bit n)
ODR0x0COutput level (bit n), or pull-up selection for inputs. A read-modify-write.
BSRR0x10Bit n set pin n high. Bit n + 16 reset it low. A 0 changes nothing. One atomic write.
BRR0x14Bit n resets pin n only

Active-low LED on PC13: BSRR = 1U << (13 + 16) turns it on, and BSRR = 1U << 13 turns it off. Use BSRR whenever an ISR may touch the same port.
