Reference · lessons 115 and 16 to 91

Interview question bank

The forty questions that come up most in junior embedded interviews, grouped by topic. Each answer is two lines. Say your own version out loud first, then compare. The practice quiz in lesson 115 drills them in depth.

C and data

#QuestionTwo-line answerLesson
1What does volatile do, and when do you need it?It tells the compiler that a value can change outside the visible code (an ISR or hardware), so each access reads memory. Use it for registers and for flags shared with an ISR; it gives no atomicity.46
2What is the type of uint8_t a + uint8_t b?Both operands are promoted to int first, so the sum is an int. It wraps only when it is stored back into an 8-bit variable.45
3Why is signed integer overflow dangerous?It is undefined behaviour, so the compiler may assume it never happens and optimise on that basis. Unsigned arithmetic wraps modulo 2N and is defined.45
4What does static mean at file scope and inside a function?At file scope it gives internal linkage, so other files cannot name the variable. Inside a function it keeps the value between calls; both have static storage duration.46
5How do you access a memory-mapped register from C?Cast the fixed address to a pointer to volatile of the register type, and dereference it. CMSIS headers wrap this in macros.47
6When do you use a macro and when a static inline function?Use a macro for text substitution, parenthesising each argument. Use a static inline function when you need types and single evaluation of the arguments.50
7Why avoid bit-fields for hardware registers?Their layout (bit order and padding) is implementation-defined. Masks and shifts give the same layout on every compiler.48
8How do you read a big-endian 16-bit value from a byte buffer?Combine the bytes with shifts and OR: (p[0] << 8) | p[1]. This avoids alignment faults and casting the buffer.48

Architecture

#QuestionTwo-line answerLesson
9Which way does the Cortex-M stack grow?Downwards: it is a full descending stack, so a push decrements the stack pointer first. An overflow writes into the memory below the stack.33
10What does the hardware stack on exception entry?R0 to R3, R12, LR, PC and xPSR. Software saves R4 to R11 in the handler, for example during a context switch.34
11How does the CPU find the ISR for an interrupt?It reads the handler address from the vector table, which sits at a fixed base address. The table is set up by the startup code and the linker script.49
12Is the Cortex-M3 von Neumann or Harvard?It has separate instruction and data buses (a Harvard-style design) on one address space, so the two can be accessed at the same time.27
13Why can C reach a register through a pointer?The memory map fixes each peripheral's address range in the chip. The pointer just names that address.38
14Why can code in flash run slower than the same code in SRAM?Flash needs wait states at higher clock speeds, unless a cache hides them. SRAM is usually zero-wait.36

Peripherals

#QuestionTwo-line answerLesson
15I2C or SPI, for the fewest wires on the controller?I2C: two shared wires (SDA and SCL) with addresses, and pull-ups. SPI: MOSI, MISO and SCK plus one chip-select per device.60
16How long is one 8N1 UART byte at 115200 baud?Ten bit times: 10 ÷ 115200 ≈ 86.8 µs. Start, eight data bits, no parity and one stop bit.53
17What is the voltage step of a 12-bit ADC with a 3.3 V reference?3.3 V ÷ 4096 ≈ 0.806 mV per code. Input voltage = code × Vref ÷ 4096.58
18How do you set the PWM frequency from a timer?f = timer clock ÷ ((PSC + 1) × (ARR + 1)). Duty is the compare value divided by ARR + 1.59
19Why does an I2C bus need pull-up resistors?Its lines are open-drain: devices can only pull them low, so a resistor sets the idle high level. The value trades rise time against current.60
20Why is a floating input a bug?It has no defined level, so it reads noise and can change at random. Add a pull-up or pull-down, or drive the pin.16
21How do you debounce a button without blocking?Sample on a timer tick and accept a new level only after several equal reads. Never call a delay in an ISR.52
22Why does each SPI device need its own chip-select?SPI has no addresses: a device listens only while its select line is low. Shared MOSI, MISO and SCK carry the data.62

RTOS

#QuestionTwo-line answerLesson
23What is priority inversion, and how is it fixed?A high task waits for a mutex held by a low task, while a medium task keeps running. Priority inheritance raises the holder's priority while it holds the mutex.90
24Mutex or semaphore?A mutex has an owner and guards exclusive access. A semaphore counts events or permits, and any task may give it.90
25What happens in a Cortex-M context switch?PendSV saves R4 to R11 on the current task's stack, the scheduler picks the next task, and the handler restores that task's registers.88
26What may an ISR call in an RTOS?Only the ISR-safe variants, such as xQueueSendFromISR. Never call a blocking call or take a mutex from an ISR.89
27What is the rate-monotonic bound for three tasks?n(21/n − 1) = 0.7798 for n = 3. Below that total utilisation the set is guaranteed schedulable; above it the test is inconclusive.91
28How do you size a task's stack?Measure the high-water mark under the worst-case load, then add a margin. Guessing is how stack overflows reach production.91

Debugging and robustness

#QuestionTwo-line answerLesson
29A HardFault has happened. What do you read first?The HardFault status register (HFSR), then the fault status register it points to. The stacked PC shows where the fault was taken.84
30What does a watchdog do?It resets the MCU when the software stops refreshing it, so a hang becomes a restart. Refresh it in one place, after the work is proven to be progressing.84
31A global changes and no code visibly writes it. How do you find the writer?Set a watchpoint on its address in GDB, and continue until it changes. The stopped location is the writer.54
32How do you check an I2C timing problem?Capture SDA and SCL with a logic analyzer and decode the frames in PulseView. Measure the rise time against the bus specification.60

Design and practice

#QuestionTwo-line answerLesson
33How do you structure firmware so the logic runs on a PC?Keep the logic in pure modules that take values in and return values out. Put the hardware behind a thin interface that a fake can replace in tests.76
34When do you need an RTOS instead of a super-loop?When tasks need independent timing or blocking waits that a single loop cannot meet. Otherwise a super-loop with a timer tick is simpler and easier to test.86
35Why avoid malloc in firmware?The heap is small, fragments over time, and its timing is not bounded. Allocate statically at startup.78
36How do you protect a variable shared with an ISR?Disable interrupts for a short critical section, or use an atomic or a queue. Keep the section short, because it adds to the interrupt latency.57
37What do you reject in a firmware code review?Unguarded shared state, blocking calls in an ISR, and magic numbers without a named constant. Ask for a test when the change is in logic.79
38What does firmware CI run?A build for the target, the host unit tests, static analysis, and a simulated run that checks the serial output. Each push runs all of them.82
39How do you update firmware in the field safely?Write the new image to a spare slot, check it, and switch only after it boots. Keep the old image to roll back to.102
40Which compiler warnings and tools do you turn on?Build with -Wall -Wextra and treat warnings as errors. Add cppcheck with warning and style checks, and read its findings.83
