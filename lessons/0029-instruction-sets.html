Instruction sets

An instruction is just a number with fields in it. Once you can read those fields by hand, a disassembly stops being a mystery.

By the end of this lesson you can split a 16-bit Thumb instruction into its fields, decode MOVS and ADDS by hand, and encode MOVS R5, #200.

The idea

An instruction set is the list of operations a CPU understands and the binary form of each one. A RISC design (reduced instruction set computer) has a small set of simple operations, and memory is reached only through loads and stores. A CISC design (complex instruction set computer) has many instructions, some of which read and write memory as part of an arithmetic operation. The label is a rough guide. Thumb-2 mixes 16-bit and 32-bit instructions, so "RISC" does not mean "tiny". Judge a design by how its instructions are encoded and how memory is accessed.

The Cortex-M3 runs Thumb-2. Arm's TRM says the core implements a Thumb instruction set subset of "all base Thumb instructions, 16-bit and 32-bit", and that it "cannot execute ARM instructions" (Arm Cortex-M3 TRM DDI0337G, §1.1 and §2.1.2). So a Cortex-M3 program mixes 16-bit and 32-bit instructions. The Cortex-M0+ implements the Armv6-M architecture (Arm Cortex-M0+ datasheet).

An encoding is the rule that maps an instruction to bits. A 16-bit Thumb encoding is a few fixed bits, which identify the operation, and fields, which hold register numbers and immediate values. Read the fixed bits first, then the fields.

Two encodings, decoded by hand

MOVS Rd, #imm8 has the fixed bits 00100 in bits 15 to 11, then a 3-bit destination register Rd in bits 10 to 8, then an 8-bit immediate. The value 0x2005 is MOVS R0, #5. Click the register below: each bit is labelled with its position, and the fields are drawn under the bits.

ADDS Rd, Rn, Rm (the register form) has the fixed bits 0001100 in bits 15 to 9, then Rm in bits 8 to 6, Rn in bits 5 to 3 and Rd in bits 2 to 0. The value 0x18D1 is ADDS R1, R2, R3.

The fields are the same for every instance. Only the values change. The examples were checked against the GNU assembler and disassembler for the Arm toolchain, so the bit patterns are the ones the tools produce. The Armv7-M Architecture Reference Manual defines the encodings formally (Armv7-M ARM, DDI0403); we did not check the ARM text itself, so use the disassembler output as the working reference. Each field is a binary number. The register fields here are 3 bits wide, so they can name only R0 to R7. That is why the 16-bit forms are limited to the low registers.

Do not decode the bits by eye with the wrong width. 0x2005 has its register at bits 10 to 8, not 11 to 9. Writing the wrong range gives a plausible but wrong register number, which is the most common mistake in this kind of work.

Try it: encode an instruction

Your task: set the bits in the empty register below so that they encode MOVS R5, #200. Work out the fields first: Rd is 5, and the immediate is 200. Then click the bits. The widget shows the hex value, which you can check against the quiz answer.

  1. Write Rd as 3 binary digits, then put them in bits 10 to 8, and add the fixed 00100 in bits 15 to 11.
  2. Write 200 as 8 binary digits, and put them in bits 7 to 0.
  3. Compare your value with the hex result. You will know it works when the widget shows 0x25C8.
Hint

200 is 1100 1000 in binary. Rd = 5 is 101. Put 101 in bits 10 to 8, and the fixed 00100 in bits 15 to 11. Then combine them.

You read a real 16-bit Thumb instruction field by field, and you encoded one from its assembly form. That is the skill you need to read any disassembly line.

"What is the difference between RISC and CISC, and what does Thumb-2 change about the Cortex-M instruction set?" Answer out loud in 60 seconds, then compare.

Model answer

RISC keeps the operations simple and reaches memory only through loads and stores. CISC allows memory operands in ordinary instructions. Thumb-2 keeps the compact 16-bit Thumb instructions and adds 32-bit ones, so the core can run dense code and still reach the full set of operations.

Armv7-M Architecture Reference Manual (DDI0403): the formal encodings for every Thumb instruction. We used the toolchain's disassembler as a check and did not read the ARM text for this lesson, so use the manual to confirm any encoding you need for a real project.
