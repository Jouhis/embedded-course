Checkpoint 3: Embedded C

Lessons 45 to 50 are the C you need to read a register map and a driver without help. This checkpoint mixes them, so you have to pick the right rule for each question.

By the end of this checkpoint you can predict integer results on fixed-width types, explain why a shared flag needs volatile, write a register access that is atomic, parse a big-endian buffer, use a callback table safely, and choose between a macro and a function.

Answer the questions below without notes first. The explanations tell you which lesson to revisit when you miss one. Then answer the three explain-out-loud prompts at the end, as if to a colleague. The integer rules come from the cppreference page on conversions.

Which lessons to revisit

  • Integer promotion, unsigned wrap and signed overflow (questions 1 to 3): lesson 45.
  • volatile, const and static (questions 4 to 7): lesson 46.
  • Register structs and atomic BSRR writes (questions 8 to 10): lesson 47.
  • Big-endian parsing, bit-fields and packing (questions 11 and 12): lesson 48.
  • Function pointers and callback tables (questions 13 and 14): lesson 49.
  • The preprocessor and multi-target builds (questions 15 to 17): lesson 50.

If you missed three or more questions in one lesson, redo that lesson's hands-on project before moving on. The projects are in projects/0046-volatile-flag to projects/0050-multi-target.
