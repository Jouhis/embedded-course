Logic gates and Boolean algebra

Every adder, comparator and address decoder in your MCU is built from a few gates. You will build an exclusive-OR from AND, OR and NOT, and check it against its truth table, with the Pico as the test bench.

By the end of this lesson you can write the truth table of a gate circuit, rewrite an expression with De Morgan's laws, and wire a gate circuit in Wokwi so that the Pico's test bench prints TRUTH TABLE OK.

The idea

A logic gate takes one or two input bits and gives one output bit. The output depends only on the current inputs, with no memory. A truth table lists the output for every input combination. For two inputs there are four rows, and the table is the complete specification of the gate. Harris and Harris, chapter 2 (Combinational Logic Design) gives the full set of gate symbols and tables.

NOT has one input. It flips its input, so NOT 0 is 1 and NOT 1 is 0. NAND is NOT AND, and NOR is NOT OR. The bubble on a gate symbol means "invert the output".

Boolean algebra: writing the same function two ways

Boolean algebra is the notation for gate circuits. A dot or AND is written as multiplication (A·B), OR as addition (A + B), and NOT as an overbar. You can rewrite an expression without changing its truth table. The most useful rules are the identities with 0 and 1, and De Morgan's laws:

NOT (A AND B) = (NOT A) OR (NOT B)
NOT (A OR B) = (NOT A) AND (NOT B)

A quick check: the left side of the first law is 0 only when both A and B are 1, and the right side is 0 only when both are 1. Two expressions with identical truth tables are the same function, however different they look. Synthesis tools and chip designers use this to make the cheapest gate circuit for a given function.

NAND is enough

NAND alone can build every other gate. NOT A is NAND(A, A). AND is NOT of NAND, so two NAND gates make an AND. OR follows from De Morgan: A OR B = NAND(NOT A, NOT B). This is why many chips are built from NAND gates, and why the nand2tetris course starts there. The same is true of NOR. Both are called universal gates. XOR is not universal on its own, so it is always built from other gates. nand2tetris builds a full computer from NAND gates upwards, and Ben Eater's video "Making logic gates from transistors" shows the transistor version of the same gates.

Try it in Wokwi

The starter circuit in projects/0022-logic-gates/starter has two inputs driven by the Pico (GP2 for A, GP3 for B), an output read on GP10, and four gates. The Pico drives every combination of A and B, and prints each result. It compares the result with exclusive OR, and prints TRUTH TABLE OK only if all four rows match.

  1. Open the starter folder in VS Code (File → Open Folder).
  2. Build with Ctrl+Shift+B. Then start the simulator with F1 → Wokwi: Start Simulator.
  3. Read the serial monitor. Some rows print WRONG, and the table fails. Look at the gates: one input of the second AND gate is not connected, so its output is unreliable.
  4. Find the missing wire. The output of the NOT gate should feed input B of the second AND gate. In diagram.json, add this line to the connections list, then save:
    ["not1:OUT", "and2:B", "orange", []]
  5. Still in the starter folder, open main.c. Find the TODO(learner) in expected_out(), and write the exclusive-OR of a and b.
  6. Rebuild, restart the simulator, and watch the table. You will know it works when the serial monitor shows TRUTH TABLE OK.
Hint for the wiring

Each gate has inputs and an output. In this circuit, the NOT gate's input is the first AND gate's output, and the NOT gate's output must go to the second AND gate. A floating input reads as an unknown level, so the row is wrong even though the logic is right.

Hint for the expression

Exclusive OR is 1 when the inputs differ. In C, the != operator on two bool values does exactly that.

The reference solution is in projects/0022-logic-gates/solution. Try first, compare after. Its test bench is the same, so the output lines match.

The Wokwi gate parts take their pin names from the part's own page. The inputs are A and B, and the output is OUT. The NOT gate uses IN and OUT. If a wire is rejected, check the pin name in the part's documentation.

"Show that NAND gates alone can build an XOR. How many gates?" Answer out loud in 60 seconds, then compare.

Model answer

XOR takes four NAND gates in the standard form: NAND(A, B) = n1; NAND(A, n1) = n2; NAND(B, n1) = n3; NAND(n2, n3) = A XOR B. Each step is a NAND, so the answer is 4. Check the truth table to see why: n1 is 0 only when both inputs are 1, and the final NAND is 1 unless both n2 and n3 are 1, which happens only when A and B differ.
